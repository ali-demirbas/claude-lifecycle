# 0.3.0 third audit: eight independent reviews of the repo at 24d3848

Eight reviewers, each with its own angle and no sight of the others' notes, read the repo as it stood at `24d3848`: validator mutation, instruction layer, patterns a–l, patterns m–z, the rest of the knowledge layer, the pipeline scripts and tests, the user-facing templates, and a first-run walk-through as a marketer. They raised 262 rows; after merging duplicates and checking each claim against the code, 60 were fixed in `release/0.3.0`, 11 did not reproduce or were judgment calls left as they are, and the rest are listed below as open.

Every fix below has a regression test in `scripts/tests/run_tests.sh` ("audit 3" section) unless marked *text*. The mutant fixtures live in `scripts/tests/fixtures/audit3/`.
