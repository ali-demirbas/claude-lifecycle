## Not adopted

- **Asking users to reopen a channel they closed** (CON-272) conflicts with this repo's consent rules. Closed channels stay closed. Re-permission happens only when the user acts, and only an authoritative consent event records it.
- **"An inferred co-purchase pairing is insufficient on its own"** — not adopted as a ban. The lift-based ranking stays, gated by brand-configured data-sufficiency thresholds (see upsell-cross-sell).
- **Operational flows** — delivery delay, refund notice, complaint resolution, appointment reminder, missing document. They are used as suppression signals (an open issue pauses marketing), not as patterns.
