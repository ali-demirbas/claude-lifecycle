# 0.3.0 external review: closure evidence per finding

A passing suite is not closure evidence. This table says, for each finding, what changed, what behavior it fixed, and which test proves it. "Red → green" means the test was run on the code before the fix and failed there, then passed on the fixed code. The pre-fix code is the parent of the first fix commit, or the commit just before a later fix. Old-code runs swapped in the new schema where needed, so that a test fails for the defect it targets and not because of an unrelated new field.

Evidence types:
- **exec**: an executable regression test, red → green.
- **exec (partial)**: a test that covers part of the fix; the gap is named in the table.
- **text**: guidance only, with no executable check.
- **design**: a deliberate choice, not a defect.
