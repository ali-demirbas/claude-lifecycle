# 0.3.0 fifth audit: seven independent reviews

Seven reviewers read the repo at `4e0065d`, each from one angle: a hostile review of the previous fix commit, a scripted end-to-end dry run of the pipeline (from the repo and from outside it, as an installed plugin), the copy validator, the schema and portfolio registry, the eval layer, docs and install, and the domain logic of every skill and agent. They also re-checked every item the third audit left open. Each claim below was reproduced against the code before it was fixed; the fixtures are in `scripts/tests/fixtures/audit5/` and the tests in the "audit 5" section of `scripts/tests/run_tests.sh`.

## Regressions the previous fix commit introduced, now fixed

- **Install mode was broken.** Script calls used `${CLAUDE_PLUGIN_ROOT:-.}`; the CLI substitutes only the plain `${CLAUDE_PLUGIN_ROOT}`, so an installed plugin looked for `scripts/` in the user's project. All calls now use the plain, quoted form.
- **Open detection** failed product events (`first_open`, `app_open`, `account_opened`); it now matches message-open names only.
- **Promotion detection** failed real service sends ("we offer 24/7 support", "teklif talebiniz alındı") and missed real promotions ("20% off", "%20 indirim"). Clear promotional constructions are an error; a promotional word alone is a note to confirm.
- **Back-to-back instances** were counted from the last send even when a new instance can only start after the first one exits; `restart` was not checked at all. Each `on_duplicate_trigger` mode now has its own start time, and a cooldown is respected.
- **The canvas merge stub** hid the rest of the journey on later branches. Shared steps are drawn in full again; the pointer is used only when a graph would explode.
- **`allowed_channels`** had been narrowed to marketing sends; it applies to every send again (it is the brand's live channel list).
- **Ranged anchors** dropped the push-per-day and reentry loads of the long end.
- **Daily push cap** failed pushes 15 hours apart; two pushes under 13 hours apart fail, 13–24 hours is a note.
- **Tooltip constants** had to be raw JavaScript; plain text broke the whole canvas. They are plain text now.
- **Input gate** flagged ordinary data ("don't ignore the care instructions", "System: Android"); the phrases are narrower and the free-text-only ones run on text columns.
- Smaller ones: branch display labels were never shown; an old manifest's run id made `start` refuse to run; a failed journey also got a misleading consistency failure.

## Other fixes

- **Copy validator:** Limit cells written as a range (`20–50`) were skipped with every check on that row; now parsed, both bounds checked. Subject and preheader minimums, word-form discounts ("yüzde 40", "yarı fiyatına", "2 al 1 öde"), the journey's own `max_discount_pct` when no flag is passed, Turkish `## Adım` / `### Varyant` docs, a field label hiding a variable in the Fallback, dashes and HTML in prose fallbacks, two CTA rows, emoji rules, SMS opt-out and link shorteners, unknown field names (`Body` for in-app, `Metin`, `Önizleme`) and a doc where no row parses.
- **Copy canvas** is generated from the reviewed doc (`scripts/copy_canvas.py`), escaped, and compared step by step and variant by variant; a hand-written canvas could show swapped or stale text and raw HTML.
- **Portfolio registry** has a schema (`templates/portfolio.schema.json`). Caps may only tighten; overlaps must name known groups; unknown channel keys and negative counts fail; several groups with no declared overlaps are assumed to coincide; `allowed_channels` at registry level is checked against every journey.
- **Run bookkeeping:** `finish` compares each journey with the run's own stage map (DQS, tier, depth, low volume), fails when the dossier is missing or when copy is in scope without `--max-discount` and `--sector`, checks and hashes the copy canvas, and moves a previous canvas aside when the run fails. `validate_output.py all` skips archived runs and exports and checks the delivered canvases.
- **Robustness:** a malformed journey or registry stops after its schema errors instead of crashing; any remaining crash prints a FAIL line; bad flag values are usage errors.
- **Evals:** unknown assertion keys fail; outputs from the old pipeline (schema 1.x, no run manifest) fail instead of passing; audience exclusion is checked where exclusions live; results cases run the results skill; breadth comes from the intake; the project folder is pinned; feed-dependent patterns are blocked at T3.
- **Canvas language:** an English run gets an English interface (`lang` in `_meta.json`); the published demos match the templates again.
- **Instructions:** brand configs live in `output/brands/`, never in the plugin folder; a frequency-cap breach is reported and waits for the user; the portfolio cooldown no longer overrides per-instance patterns; the architect gets volume, timezone and precedence facts; a blocked single-journey request stops and offers the closest eligible pattern; non-interactive defaults are stated for breadth, overlap class, copy tone and unmapped events.
- **Install:** `.claude-plugin/marketplace.json`, working install commands in the README, the T2-aggregate tier, Python and Windows requirements, third-party notices for the icons.
