# 0.3.0 findings ledger

Every defect fixed in 0.3.0, with where it lived, a concrete instance, the expected behavior, and the test that now catches it. Instances come from four real 0.2.0 runs, preserved unmodified; they are anonymized here as Runs A–D. Run D used fictional test data.

The pre-fix test log shows 27 of the 41 acceptance tests failing against the 0.2.0 validator. The 0.2.0 validator passed Runs A, B and C outright.

## External review of the 0.3.0 package (32 findings)

An external review read the bundled 0.3.0 content without the scripts. Each finding was then reproduced against the real validator and repo, and classified:
- **confirmed**: reproduced and fixed;
- **partly handled**: an existing rule or check already covered part of it;
- **by design**: deliberately left as is.
